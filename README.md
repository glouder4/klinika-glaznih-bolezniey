# 🏥 Система управления записями "Клиника глазных болезней"

Комплексная система управления записями пациентов и расписанием врачей для медицинской клиники, построенная на платформе **Bitrix24**.

## 📋 Описание

Система предназначена для автоматизации процессов записи пациентов в клинику глазных болезней. Она обеспечивает:

- 📅 **Управление записями** - создание, редактирование, отмена записей
- 👨‍⚕️ **Расписание врачей** - контроль доступности времени, перенос записей
- 🏢 **Многофилиальность** - управление несколькими отделениями клиники
- 🌍 **Часовые пояса** - поддержка разных временных зон для филиалов
- 🔗 **Интеграция CRM** - работа с контактами и сделками Bitrix24
- 📊 **Статистика** - отчеты по записям и загруженности врачей

## 🚀 Быстрый старт

1. Установите модуль через админ-панель Bitrix24
2. Настройте филиалы клиники
3. Назначьте сотрудников к филиалам
4. **⚠️ Выдайте права доступа к файлам Bitrix для новых групп** (см. [docs/INSTALLATION.md](docs/INSTALLATION.md#3-настройка-прав-доступа-к-файлам-bitrix))
5. Настройте часовые пояса
6. Создайте первую запись

**Подробные инструкции**: См. [docs/INSTALLATION.md](docs/INSTALLATION.md)
